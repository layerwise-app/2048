# 2048

2048 is a sliding tile puzzle you can play in the browser. Slide the board with
the arrow keys or a swipe, merge matching numbers, and try to build a 2048 tile
before the board fills up. Moves and merges make small synthesized sounds, and
your game and best score are saved in the browser. Players who sign in can
submit a finished game to a shared Top 100 leaderboard and see their own score
history on a dashboard. It's a starting point for anyone who wants a small,
polished browser game with accounts and a leaderboard already wired up.

Play the live demo at <https://2048.layerwise.site/>.

It was built with [Layerwise](https://layerwise.app), and you can open it in
Layerwise to make your own version.

## Changing it

- **Game rules and board.** `src/components/Game2048.tsx` holds the whole game:
  moving and merging tiles, the new tile spawn (a 2 nine times out of ten,
  otherwise a 4), the win check at 2048, keyboard and swipe input, and the
  sounds in `useAudio`. `BOARD_PX` and `GAP_PX` at the top set the board's
  maximum width and the gap between cells. The board's layout is written for a
  4 × 4 grid.
- **Tile colors.** `TILE_STYLES` in `src/components/Game2048.tsx` maps each
  tile value to its background and text color (plus a glow from 128 up), and
  `FONT_SIZES` sets each value's text size. Tiles above 2048 fall back to
  `bg-[#3c3a32] text-white` and `text-3xl`. To give a value such as 4096 its own look, add a key for it to
  both maps.
- **Page colors.** The cream page background (`#faf8ef`, `#1b1917` in dark
  mode), the brown buttons (`#8f7a66`), and the gold buttons (`#edc22e`) are
  Tailwind classes in the route files and `Game2048.tsx`. The tile pop,
  appear, and shake animations are in `src/styles/app.css`. The font is
  Outfit, set in `src/styles/app.css`.
- **Copy.** The tagline ("Join tiles, reach 2048."), the controls hint, and the
  "Game over!" and "You win!" screens are in `src/components/Game2048.tsx`. The
  "2048" wordmark is `src/components/GameLogo.tsx`.
- **Page titles and descriptions.** Each route sets its own with `seo()` from
  `src/utils/seo.ts`; `src/routes/__root.tsx` sets the default used by pages
  that don't.
- **Logo and icons.** `public/logo.svg` is the source for `public/logo.png` and
  the favicons in `public/`. The app name for home screen installs is in
  `public/site.webmanifest`.
- **Layerwise credit.** The "Make your own game with Layerwise" link is
  `src/components/powered-by-layerwise.tsx`, placed in the bottom-right corner
  of the home page by `src/routes/index.tsx`. It ignores swipes that end on it,
  so a swipe that runs off the board can't open it.

## Scores and accounts

Scores are stored in the `game_scores` table in `src/db/schema.ts`. The server
functions in `src/lib/scores.functions.ts` save a score (whole numbers from 0
to 3,932,100), read the top 100, and read a player's latest 200 games. Players
choose to submit from the game-over and win screens, and only signed-in
players can submit.

Accounts use Better Auth, configured in `src/lib/auth.ts`, with email and
password sign-in, one-time email codes (6 digits, valid for 5 minutes, 3
attempts), and the admin plugin. `src/lib/auth-email.ts` sends codes to
`AUTH_EMAIL_URL`; if that isn't set, the code is printed to the server log
instead. The user, session, account, and verification tables in
`src/db/schema.ts` are generated by Better Auth.

## Commands

```bash
pnpm dev
pnpm check-types
pnpm build
pnpm auth:generate
pnpm db:generate --name <migration_name>
pnpm db:migrate
pnpm cf-typegen
pnpm release
```

`db:migrate` applies generated Drizzle migrations to the local D1 database.
Layerwise applies the same migrations to the project's production D1 database
during publishing.

## Other important files

- `src/routes/api/auth/$.ts`: Better Auth request handler
- `src/lib/auth.functions.ts`: client-callable server functions
- `vite.config.ts`: Cloudflare, TanStack Start, React, Tailwind, and Layerwise
  plugins
- `wrangler.jsonc`: local Worker and D1 bindings

Keep secrets server-side. Variables prefixed with `VITE_` are included in the
browser bundle. `BETTER_AUTH_SECRET`, `BETTER_AUTH_URL`, and `AUTH_EMAIL_URL`
belong in the Worker environment.
